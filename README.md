# Smart Garden Manager
[![Static Badge](https://img.shields.io/badge/SMART%20GARDEN%20MANAGER%20-%20V.%200.1%20-%20GREEN?style=for-the-badge&logoColor=%2311734b&labelColor=%23dcbc91&color=%2311734b&link=https%3A%2F%2Fgithub.com%2FFabio-Stuber%2FSmart-Garden-Manager%2Ftree%2Fmain)](https://github.com/Fabio-Stuber/Smart-Garden-Manager/tree/main)

The Smart Garden Manager is a standalone web application for managing gardens and plants.

The Smart Garden Manager bridges the gap between traditional gardening knowledge and modern smart home technology. It is a standalone web application that serves as an intelligent control center for the garden. It combines the visual and planning depth of a gardening journal (as found in Excel or reference books) with the automation capabilities of Home Assistant.
